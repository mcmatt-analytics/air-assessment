This repo contains 4 markdown files that detail my approach to the assessment.  Given I only had 4 hours the project is incomplete, but should cover the essentials necessary for Air to scaffold a quality data model across the various surface areas.

It will be obvious that I used Claude here, but please note that the concepts, designs, and key considerations are all mine.  The effort was more of a coaxing and guiding Claude to match my vision, rather than asking it to do everything. This is for good reason as Claude can make many mistakes.

## Contents

- [`metrics_list.md`](metrics_list.md) — KPIs and supporting metrics per surface area (stage).
- [`data_model.md`](data_model.md) — Overview of downstream tables built from raw sources.
- [`system_diagram.md`](system_diagram.md) — Diagram of the model above.
- [`reporting_surfaces.md`](reporting_surfaces.md) — Where employees consume this data (BI explores/dashboards) and rules for building on the semantic layer vs. routing around it.

## Reading order

`metrics_list.md` → `data_model.md` → `system_diagram.md` → `reporting_surfaces.md`

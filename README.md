This repo contains 4 markdown files that detail my approach to the assessment.  Given I only had 4 hours, the project is incomplete, but should cover the essentials necessary for Air to scaffold a quality data model across the various surface areas.

It will be obvious that I used Claude here, but please note that the concepts, designs, and key considerations are all mine.  The effort was more of a coaxing and guiding Claude to match my vision, rather than asking it to do everything. This is for good reason as Claude often makes mistakes.
